A quick-reference + interview-prep KB. Each file is self-contained and skimmable.

## How to use this KB
- **Before an interview:** skim the cheat sheet + complexity table.
- **During study:** read one area file end-to-end, then answer the self-test questions at the bottom.
- **Quick lookup:** search for a keyword (e.g. `sharding`, `B-tree`) and jump to the section.
